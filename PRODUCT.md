# Agent Intent

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Connect project intent and high-level requirements to executable Gherkin,
component specifications, test results and the evidence captured by step glue.
Reviewers inspect that evidence before accepting specification changes.

## Operating Context

The CLI serves a local interactive report and exports standalone HTML reports.
Toybox Trebuchet exercises the tool as a consuming project.

## Capabilities and Constraints

Requirements, end-to-end scenarios and components keep independent test results.
Reviewers can inspect step logs and test source. Specification acceptance is a
human decision recorded separately from execution results.

The current request calls for a reworked report layout and the visible name
“Components” for the subsystem feature view.
