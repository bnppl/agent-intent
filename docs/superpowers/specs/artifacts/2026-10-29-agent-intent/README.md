# Interactive design artifacts

These are conceptual diagrams from the product discussion, not a working Agent Intent implementation. Approval controls and mutation results are simulated and are not persisted as real approval records.

- **[Current iteration flow](iteration-flow.html):** small learning iterations, zoomable abstraction levels, editable draft IDs, lineage, explicit batch agreement, optional implementation approval, scope concerns and two mutation-testing passes.
- **[Earlier lifecycle exploration](lifecycle.html):** the initial five-stage model, retained as historical design context. The current flow supersedes it where the two differ.
- Editable inline sources: [current fragment](iteration-flow.fragment.html) and [earlier fragment](lifecycle.fragment.html).
- [Product specification](../../2026-10-29-agent-intent-product-design.md).

Download either complete `.html` file and open it in a browser. No server or build is needed. GitHub's source viewer does not execute the diagrams. The complete exports embed the styles and interaction runtime needed outside ChatGPT.

The court-booking scenarios illustrate the workflow; they are not new executable Agent Intent requirements. Scope-blocking policy and other undecided questions are recorded in the product specification.
